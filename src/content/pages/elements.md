This page shows how each piece of Markdown looks on the site. The first paragraph of a post always appears larger, like this one, as an introduction.

## A section heading (##)

Normal paragraphs look like this. You can use **bold text** for key phrases and [links like this one](/blog/). Links to other websites open in a new tab.

### A smaller heading (###)

Bullet lists use a dash at the start of each line:

- Who will the domain be registered to?
- Will I have my own hosting login?
- What does the handover process look like if I want to leave?

Numbered lists use numbers:

1. Book a free call
2. Talk through what you need
3. Get a fixed quote

> A quote block, written with a > at the start of the line, becomes a pull quote.

## Images

Write `![Description of the image](/images/blog/domain.jpg)` and put the file in `src/assets/images/blog/`. It is resized and compressed automatically.
